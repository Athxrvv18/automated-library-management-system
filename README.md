# 📖 About the Project

The **Automated Library Management System (ALMS)** is an IoT-based smart library automation project developed to automate and simplify conventional library book issue and return operations.

Traditional library systems often depend heavily on manual entry for recording books, users, issue dates, return dates, availability, and fines. ALMS addresses these challenges by integrating **IoT hardware, barcode scanning, database management, server communication, and a web-based administration dashboard** into one connected system.

The physical automation terminal uses a **Raspberry Pi**, **IR sensors**, and a **camera-based barcode scanner**. The IR sensors determine whether the user is performing an **issue** or **return** operation. The camera is then used to scan the required book and user identifiers.

After scanning, the transaction is processed and the relevant database information is updated. The system also supports automatic due-date and overdue-fine calculation.

The IoT communication layer allows transaction information generated by the physical terminal to be synchronized with the server/cloud infrastructure.


# 📷 Barcode Scanning

The Raspberry Pi terminal uses a camera to capture frames and detect barcodes.

The scanning pipeline is:

```text
Camera
   ↓
Image Frame
   ↓
OpenCV
   ↓
Pyzbar Barcode Decoder
   ↓
Barcode Data
   ↓
Book/User ID
```

The scanner also uses a timeout mechanism so that the system does not wait indefinitely for a barcode.

---

# 🗄️ Database Management

The system uses **MySQL** for library transaction data.

The Raspberry Pi implementation works with a `bookdatabase` table containing fields such as:

```text
uid
available
issuedto
issuedate
returndate
```

### During Issue

The system updates:

```text
available = 0
issuedto   = User ID
issuedate  = Current Date/Time
returndate = Calculated Due Date
```

### During Return

The system updates:

```text
available = 1
issuedto   = NULL
issuedate  = NULL
returndate = NULL
```

# 📅 Due Date Calculation

The current Raspberry Pi implementation provides a **7-day borrowing period**.

For example:

```text
Issue Date:
15 September

Due Date:
22 September
```

The return date is automatically calculated using the issue date.

---

# 💰 Automatic Fine Calculation

ALMS includes automatic overdue fine calculation.

The current configuration uses:

```text
Fine = ₹5 × Number of Late Days
```

### Example

```text
Due Date       → 10 September
Actual Return  → 13 September

Late Days      → 3

Fine           → 3 × ₹5
               → ₹15
```

The calculated fine is included in the return transaction sent to the server.

# ☁️ IoT & Cloud Communication

The project includes an IoT communication layer consisting of:

```text
iot_device.py
iot_server.py
```

The Raspberry Pi terminal can send transaction information to a configured server endpoint.

### Issue Event

```json
{
  "action": "issue",
  "book": "BOOK_ID",
  "user": "USER_ID"
}
```

### Return Event

```json
{
  "action": "return",
  "book": "BOOK_ID",
  "user": "USER_ID",
  "fine": 15
}
```

This architecture allows the physical library terminal to communicate with the online system.
